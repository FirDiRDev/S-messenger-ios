# Оплата монет в S-messenger (ЮMoney, кошелёк физлица)

Паки: «Стартовый набор» 99 ₽ → 250, «Горсть» 150 ₽ → 300, «Мешок» 300 ₽ → 600,
«Сундук» 500 ₽ → 1500, «Королевский клад» 1000 ₽ → 3500 монет.
«Фишки для Блэкджека» (те же монеты, раздел в магазине): «Стопка фишек» 249 ₽ → 700,
«Кейс крупье» 749 ₽ → 2400, «Хайроллер» 1490 ₽ → 5500 (id `bj_stack`, `bj_case`, `bj_highroller`). Донат «на жизнь проекта» -
любые суммы (label = donate), монеты за донат не начисляются.

Как это работает: приложение открывает форму оплаты ЮMoney, в `label` уходит секретный ID
покупок игрока. ЮMoney присылает уведомление серверу, сервер проверяет подпись и сумму и
выпускает чек, подписанный ECDSA. Приложение само забирает чек, проверяет подпись и
зачисляет монеты с анимацией. Подделать чек нельзя.

## Вариант 1 (проще всего, бесплатно): Cloudflare Workers - папка `coins-worker`
1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатный тариф).
2. **Storage & Databases → KV → Create** - назовите `COINS`.
3. **Workers & Pages → Create → Worker** → «Hello World» → Deploy → **Edit code**:
   удалите всё и вставьте содержимое `coins-worker/worker.js` → Deploy.
4. В воркере **Settings → Bindings → Add → KV namespace**: имя переменной `COINS`,
   пространство - `COINS`.
5. **Settings → Variables and Secrets**:
   - `NOTIFICATION_SECRET` (тип Secret) - секретное слово из ЮMoney (шаг 6);
   - `WALLET` (Text) - номер кошелька 41001… (виден в кошельке ЮMoney).
6. ЮMoney: https://yoomoney.ru/transfer/myservices/http-notification
   - адрес: `https://<ваш-воркер>.workers.dev/yoomoney/notify`;
   - отметьте «Отправлять HTTP-уведомления», скопируйте секретное слово в `NOTIFICATION_SECRET`.
7. Откройте в браузере `https://<ваш-воркер>.workers.dev/setup?secret=<секретное слово>` -
   сервер создаст ключи и покажет готовый блок `coinShop`.
8. Вставьте блок в `update.json` в корне репозитория (рядом с `versionCode`) и загрузите
   файл в GitHub. Через несколько минут магазин включится у всех - новую сборку делать
   не нужно.
9. В ЮMoney нажмите «Протестировать» - запись со статусом `test` (монеты не начисляются).
   Купите самый дешёвый пак (99 ₽) - монеты придут через несколько секунд.

## Вариант 2: свой сервер на Python - папка `coins`
См. `coins/README.md` (Flask + SQLite `users(user_id, coins_balance)`). Блок для
`update.json` тот же: `wallet`, `server` (адрес сервера), `publicKey` (печатает `python keys.py`).

## Блок в update.json
```json
"coinShop": {
  "wallet": "41001XXXXXXXXXXX",
  "server": "https://smessenger-coins.<имя>.workers.dev",
  "publicKey": "MFkwEwYHKoZIzj0CAQYIKoZIzj0DAQcDQgAE..."
}
```
Пока блока нет, в магазине написано «Покупка монет ещё не включена», а донат открывает
страницу сбора. Если указан только `wallet`, донат принимает любые суммы прямо на кошелёк.

## Защита от обмана
- подпись уведомления SHA-1 с секретным словом; неверная - 403, ничего не начисляется;
- каждый `operation_id` - один раз (повторы не удваивают монеты);
- протекция (`codepro`), незачисленные (`unaccepted`), не рубли - не начисляются;
- пак - по точной сумме, которую заплатил человек (`withdraw_amount`); не совпало - `unmatched`;
- чек подписан ECDSA P-256; приложение проверяет подпись, свой ID, сумму пака и
  уникальность чека и платежа в защищённой базе `coin_purchases.db` (переносится с профилем).

## Паки «Фишки для Блэкджека» (с версии 4.6.0)
Новые паки добавлены в `coins-worker/worker.js` (`PACKS`) и `coins/config.py` (`PACKS`) - одинаково
в обоих местах и в приложении (`CoinShop.CHIP_PACKS`). Чтобы они заработали, **обновите сервер**:
вставьте новый `worker.js` в редактор воркера и нажмите Deploy (или перезапустите `server.py`).
Сервер теперь отвечает на `GET /api/packs` списком паков; приложение показывает раздел
«Фишки для Блэкджека» только когда сервер вернул эти паки с теми же ценами - пока сервер не
обновлён, раздел скрыт и оплатить пак, который сервер не узнает, нельзя.
Пак определяется по точной сумме платежа, поэтому цены паков фишек не должны совпадать
с другими паками. Ключи подписи и KV не меняются.
